Fraia

Fraia is a desktop workbench for shaping structural schemes, understanding how they behave, and developing better-informed design options.

Fraia is early-stage software for preliminary work. It is not code-compliant design software and does not replace project-specific engineering review. Please report issues through GitHub Issues.
