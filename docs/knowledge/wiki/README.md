# Compiled Knowledge Wiki

_Status: active v0.2_
_Date: 2026-05-06_

This directory contains synthesized, cross-linked pages intended for Fraia agents.

Compiled pages must follow [`../schema.md`](../schema.md), appear in [`../index.md`](../index.md), appear in [`../topic-map.md`](../topic-map.md), and be logged in [`log.md`](log.md).

- [`stability/`](stability/) — bracing and stability systems.

- [`materials/`](materials/) — material/member behavior concepts.
- [`steel/`](steel/) — steel structural systems; includes the canonical portal-frame bracing page.
- [`product/`](product/) — Fraia-specific product, pipeline, provenance, and LLM-surface guidance.
